unjam RPM packages

Packages for Rocky Linux 9 and 10 (and other Enterprise Linux 9 and 10) and the latest Fedora, on x86_64 and aarch64. Install the repository configuration, then unjam:

dnf install https://gsi-hpc.github.io/unjam/rpm/unjam-release-el9.noarch.rpm     # EL 9
dnf install https://gsi-hpc.github.io/unjam/rpm/unjam-release-el10.noarch.rpm    # EL 10
dnf install https://gsi-hpc.github.io/unjam/rpm/unjam-release-fedora.noarch.rpm  # Fedora
dnf install unjam

unjam-release installs /etc/yum.repos.d/unjam.repo and the signing key RPM-GPG-KEY-unjam (fingerprint 1EC9 AAF8 6238 CE0B 2FC2 78F8 D014 7913 E1E0 5035). dnf checks the signature of each package and of the repository metadata.

The package holds the release binary without changes, so its build provenance stays valid:

gh attestation verify /usr/bin/unjam -R GSI-HPC/unjam

Source and releases: github.com/GSI-HPC/unjam
