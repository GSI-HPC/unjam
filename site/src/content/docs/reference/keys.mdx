title: Keys

## Live view

| Key | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>k</kbd> <kbd>j</kbd> | Move one row |
| <kbd>PgUp</kbd> <kbd>PgDn</kbd> | Move 20 rows |
| <kbd>Home</kbd> <kbd>End</kbd> <kbd>g</kbd> <kbd>G</kbd> | First, last row |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>h</kbd> <kbd>l</kbd> | Fold, open (also a folded node range). <kbd>←</kbd> on a leaf or folded row: go to the parent |
| <kbd>Enter</kbd> | Detail: every value of the row |
| <kbd>space</kbd> | Mark or unmark the row (a node or cgroup; on a process row, its cgroup) |
| <kbd>a</kbd> | Clear all marks |
| <kbd>p</kbd> | Level of the marked rows, or the cursor row: `p` → `c` → `o` → `p` |
| <kbd>+</kbd> <kbd>-</kbd> | Halve, double the interval of the marked rows, or the cursor row |
| <kbd>0</kbd> | Reset the rules to the defaults |
| <kbd>z</kbd> | Pause and resume |
| <kbd>v</kbd> | Next layout: step → node → flat (locally: tree ↔ flat) |
| <kbd>s</kbd> <kbd>S</kbd> | Next sort column (NAME, the values, RANK, NODE), reverse the sort |
| <kbd>/</kbd> | Edit the filter; <kbd>Enter</kbd> keeps it, <kbd>Esc</kbd> clears it. `r5` or `r0-7` also matches MPI ranks |
| <kbd>m</kbd> | Map of the cursor row's step (one cell per task) or MPI world (one cell per rank); arrows scroll, any other key closes |
| <kbd>r</kbd> | Start or stop recording to `unjam-rec-<secs>/<host>.arrows` |
| <kbd>t</kbd> | Next theme |
| <kbd>?</kbd> | Help, per-node table and log |
| <kbd>q</kbd> <kbd>Ctrl</kbd>+<kbd>C</kbd> | Quit |

## Replay

| Key | Action |
|---|---|
| <kbd>space</kbd> | Play, pause |
| <kbd>,</kbd> <kbd>.</kbd> | One tick back, forward |
| <kbd>&lt;</kbd> <kbd>&gt;</kbd> | 60 s back, forward |
| <kbd>g</kbd> <kbd>G</kbd> | Start, end |

Moving (with <kbd>Home</kbd> <kbd>End</kbd> for the first and last row), folding, <kbd>Enter</kbd>, <kbd>m</kbd>, <kbd>v</kbd>, <kbd>s</kbd>, <kbd>/</kbd>, <kbd>t</kbd>, <kbd>?</kbd> and <kbd>q</kbd> work as in a live view. <kbd>p</kbd>, <kbd>+</kbd>, <kbd>-</kbd>, <kbd>0</kbd>, <kbd>r</kbd> and <kbd>z</kbd> do nothing.

## Columns legend

| Column | Meaning |
|---|---|
| INT | The interval of the row's rule |
| W | The level of the row's rule: `p` processes, `c` cgroups, `o` off |
| PIDS `~N` | No pids controller: the sum of threads of the sampled processes |
| RANK | The MPI rank of a process, or the lowest and highest rank below a cgroup. Hidden when no row has one |
| `-` | No value |
